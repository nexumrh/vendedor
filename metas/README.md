# NexumCell — Minhas Metas

App que o funcionário abre no celular para ver **só as metas e o bônus dele**, com login próprio.

- **Equipe Nexum:** o Dono compartilha o link.
- **Lojas parceiras:** o Gerente compartilha o link com os funcionários da loja.

Usa o mesmo Firebase e o mesmo login dos outros portais (`nexumcell-config.js`). As metas e o bônus são definidos pela Nexum no Painel do Dono.
